\begin{abstract}
This projects aims to make affordable and accessible sign interpretation glove. This by using gyroscope - accelerometer sensors attached to each finger, with a Raspberry pi mounted on the hand to act as the brain. With both gyroscope and accelerometer they could complement each others flaws with a complementary filter to calculate pitch and roll of the sensor. After two weeks code had been tested and given positive results on test data, but the sensors chosen had so small dimensions that they proved difficult to work with by hand. So to continue with this project different sensor or more precise lab equipment would be required to get any real time data acquisition.

\end{abstract}
